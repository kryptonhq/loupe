On Linux and Windows, read <kbd>⌘</kbd> as <kbd>Ctrl</kbd>. Press
<kbd>?</kbd> anywhere outside a text field for this list in the app.

## Tabs and history

| Keys | Does |
| --- | --- |
| <kbd>⌘T</kbd> | New tab, on whatever is open |
| <kbd>⌘W</kbd> | Close the tab |
| <kbd>⌘1</kbd> … <kbd>⌘9</kbd> | Go to a tab by position |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | Back and forward through the tab's history |
| <kbd>⌘</kbd>-click | Open a row, or a dashboard number, in a tab of its own |
| <kbd>Esc</kbd> | Close a detail view, or the palette |

## Command palette and search

| Keys | Does |
| --- | --- |
| <kbd>⌘K</kbd> | Open or close the command palette |
| <kbd>↑</kbd> <kbd>↓</kbd> or <kbd>Ctrl-P</kbd> <kbd>Ctrl-N</kbd> | Move through results |
| <kbd>Enter</kbd> | Run the command, or open the object in this tab |
| <kbd>⌘Enter</kbd> | Open the object in a new tab |

## View

| Keys | Does |
| --- | --- |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> | Make the interface larger or smaller |
| <kbd>⌘0</kbd> | Back to the standard size |
| <kbd>?</kbd> | Show the shortcut list |

Tab and zoom shortcuts work while the cursor is in a filter box — which
is exactly where it is when you decide to open a second tab.
