*Released 3 August 2026 —
[on GitHub](https://github.com/kryptonhq/loupe/releases/tag/v0.1.1)*

A maintenance release. No user-facing behaviour changed.

### Changed

- Test coverage across the frontend and the Rust core, and a security
  pass over the repository
- Dependency updates, with major bumps kept out of the grouped
  Dependabot pull requests so they can be reviewed on their own
- Merge commits no longer require a DCO sign-off, which was blocking
  otherwise valid merges
