title: Building from source

Loupe needs Node 22, pnpm 10 and a stable Rust toolchain, plus
[Tauri's system dependencies](https://tauri.app/start/prerequisites/)
for your platform.

```bash
git clone https://github.com/kryptonhq/loupe
cd loupe
pnpm install
pnpm tauri dev
```

`pnpm dev` alone serves the frontend in a browser, where the Tauri
bridge is absent. In that case the UI falls back to the fixtures in
`src/dev/fixtures.ts`, allowing layout work without a cluster. That
path is development-only and is excluded from production builds.

## Tests

```bash
pnpm test                         # frontend, vitest
cargo test --manifest-path src-tauri/Cargo.toml   # Rust core
```
