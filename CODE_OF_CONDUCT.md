# Code of Conduct

Loupe follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

The short version: be respectful, assume good faith, and remember that
the person on the other end of the thread is doing their best with the
context they have.

## Reporting

Report unacceptable behaviour to the maintainers listed in
[MAINTAINERS.md](MAINTAINERS.md).

Reports are handled confidentially. If a report concerns a maintainer,
you may raise it with any other maintainer.
